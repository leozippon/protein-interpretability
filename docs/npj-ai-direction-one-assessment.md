# 方向一独立成文与 npj Artificial Intelligence 投稿评估

**评估日期：2026-09-05，已纳入本轮完成的生成与结构补充。** 本文评估方向一独立成文的条件，不用投稿叙事决定研究范围，不修改[科学审计与研究计划](INTERPRETABILITY_TRANSFER_AUDIT.md)，不借用方向二、三的结果承担论文贡献。

**研究问题是通过蛋白模型的生成效果，间接判断它们是否学到了生物学知识。** 方向一评估这种行为证据是否存在、有多强；具体学到了哪些规律、如何表示与实现，留给方向二、三。评分、条件／上下文使用和泛化可以作为不同维度共同支撑分析；不必先证明评分与生成分离，也不必先选一个狭窄论文故事。评分目前有最成熟的实验标签，但这些标签属于原数据中的候选，不能验证本项目生成物。npj AI 仍是有条件合理的目标。现已具备可进入作者审阅的有边界计算证据，而非只有实验计划；是否达到该刊的新颖性和重要性标准，仍须依据相对文献的具体增量判断，不能把全部任务成功执行等同于论文必然成熟。

此前三份独立意见有实质分歧：两份优先建议生成能力诊断，一份认为评分是更成熟的论文候选。这解释了证据成熟度的不同，不能替代用户随后明确的研究问题，也不预定生成结果必须支持“掌握知识”。独立意见见[能力构念](../logs/npj_ai_review/independent_capability_scope.md)、[生成证据](../logs/npj_ai_review/independent_generation_evidence.md)和[论文贡献](../logs/npj_ai_review/independent_paper_contribution.md)；本轮有限缺口见[生成补充](../logs/npj_ai_review/capability_gap_generation.md)与[评分／上下文补充](../logs/npj_ai_review/capability_gap_scoring_context.md)。

## 能力证据与文献边界

**评分检验给定候选的排序，生成检验指定程序在预算内产出什么。** 两者不是同一个问题，也不是从弱到强的单一阶梯。DMS/MegaScale 的实验标签属于其提供的候选，不能移给本项目新生成的序列；R228 则是给定目标的上下文似然评分，不是生成质量实验。

评分的主要依据仍然成立：同谱系、相同 mutant digest 的比较中，ProGen3 的 MODEL−LOOKUP 从 −0.0801 变为 +0.0555；ProGen2 三个规模的差值区间均含零；ProLLaMA 适配改善排序，却仍低于 profile 基线。MegaScale 的同平台天然/设计对照又测到模型相对疏水性、BLOSUM62 和片段基线的不同表现。它们有真实生物标签和不确定性，但并不直接回答自由生成能走多远。数值与限制见[方向一概览](../summary.md#外部蛋白任务上的序列评分)及审计 D1.e–g、F12。

来源关系须准确表述：当前 217 个 DMS assay 中有 **64 个名称含 `Tsuboyama_2023`**；[本次元数据检查](../logs/npj_ai_review/dms_source_overlap_metadata.json)只重数了名称。历史 F12 检查已匹配 **64/64 个 Tsuboyama WT**，并使 ProtGPT2、ProGen2-medium 的相关系数跨两套文件/代码重现至约 0.003；不能说从未核对 WT。当前完整 217-assay 面板与 MegaScale 的重叠及来源排除敏感性仍未完成，也未在本轮重新复现。DMS 与 MegaScale 不能作为完全独立来源的确认。

原有 R227 证据是原生条件控制：ZymCTRL、ProLLaMA 的请求减错配分别为 +0.8822、+0.1267，评价的是策展 profile 类别归属。两者标签体系不同，不能比较数值排名；其他 checkpoint 提供的生成下限也不是同模型去掉条件后的因果对照。ProLLaMA 只有 13.5% 输出获任意 Pfam 识别，既可能反映当前采样质量，也可能受评价器覆盖限制；ZymCTRL 对所搜 UniRef50 的最大 identity 中位数为 69.2%，不等于已证明记忆。正确标签优于错配不自动等于高绝对产出率，更不等于生成物有功能。

**独立成文仍须说明文献以外的增量，但这不是开展能力测量的前提。** [ProteinGym](https://proceedings.neurips.cc/paper_files/paper/2023/hash/cac723e5ff29f65e3fcbb0739ae91bee-Abstract-Datasets_and_Benchmarks.html)和 [Hou 等，2026-07-13](https://www.nature.com/articles/s43588-026-01010-z)已覆盖广泛比较及规模、似然与适应度关系；后者本轮依据官方摘要、图注及资料入口，不声称读完受限全文。生成方面，[ProteinBench](https://proceedings.iclr.cc/paper_files/paper/2025/hash/49b9d06c2dae5af46125490e0a6f9e32-Abstract-Conference.html)已系统讨论质量、新颖性、多样性与稳健性；[PDFBench v3](https://arxiv.org/html/2505.20346v3)于 **2026-07-04** 更新为 **8 个模型、16 项指标**，也报告对齐、参考相似性与多样性的权衡。增加这些指标本身不是新贡献。

已有[ProGen 实验](https://www.nature.com/articles/s41587-022-01618-2)和 [ESM3 研究](https://www.science.org/doi/10.1126/science.ads0018)分别展示活性蛋白和荧光设计；[生成酶指标研究](https://www.nature.com/articles/s41587-024-02214-2)已把计算指标与实验结果、候选筛选相连接。因此，本项目的计算结果不能声称全领域的生成上限，也不能仅凭“评分不等于功能”成文。这些外部成果属于各自训练、采样、筛选和实验流程，不验证本项目的样本。

## 本轮补充回答了什么，仍有哪些边界

本轮遵守用户明确的“是否学到了知识”问题：评价生成物，不把具体催化位点、规律识别或内部机制加成方向一的必需项。冻结的 [R232](D1_GENERATION_BIOLOGY_PREREGISTRATION.md) 保留全部 12,800 次原尝试，分开报告目标识别、任意 profile、跨类映射与非冗余产出；[R233](D1_PROGEN3_GENERATION_PREREGISTRATION.md) 则实际通过 3B 特异接口门，完成一次具名 ProGen3 原生无条件生成任务。旧文中“原生接口未验证”已被实际运行取代。

**结构补充已形成结果。** 天然／自身组成扰乱 pilot 的 116 个预测全部完成，两个面板均通过冻结校准。随后 2,320 个 main 预测、1,160 对全部成功。ZymCTRL 的请求生成物减自身扰乱 mean CA-pLDDT 为 +56.68，97.5% 类别 bootstrap 区间 [45.90, 62.57]；ProLLaMA 为 +5.92 [2.49, 10.57]。这支持两者生成顺序包含超出长度和组成、可被该预测器识别的信息；同时，绝对 confidence event 全尝试估计分别约 86.36% 和 1.36%，说明正 margin 不能代替高绝对产率。后者一个短序列未知使支持上界为 1.40%；支持范围不是置信区间或实测成功率。

**新增原生任务也已完成。** ProGen3-3B 的 800 次尝试中，501 个由 native compiler 接受、299 个在预算处形成截断前缀；496 个获任意 Pfam 识别。128 个抽样产物与 128 个自身扰乱均预测成功，combined mean-confidence margin 为 +38.39，95% 序列组区间 [34.53, 42.27]。样本中 89 个原生编译输出和 39 个截断前缀分别保留；正 primary 是固定任务上的前缀包含估计，不能把置信度转写成完整产物或跨家族成功。参考命中、同一命中的身份与覆盖及原始未命中状态都保留，R232 fresh 检索与 legacy 身份分开核对，原字段全部保留，7,043 个既有非空 identity 数值逐值不变。主要请求队列有参考命中比例为 ZymCTRL 2,658/2,800、ProLLaMA 390/3,000，同一产物的参考支持与置信度一起报告；这限制训练外推广，但不构成记忆的因果证明。

这些结果给出强弱不同的**生成行为间接证据**。家族相容性、预测器认可的结构顺序和对应候选的表达／折叠／功能实测不构成同一个总分；本项目目前只有前两类计算通道。天然／扰乱校准检验序列顺序，不是实测可折叠／不可折叠特异性。低参考相似也不等于完整训练外。超过所有 profile／检索基线、获得完全训练外证书，不是支持有限知识存在的普遍前提；但没有排除的替代解释约束更强主张。阴性和低产出也不能证明模型没有知识。

**本轮有限范围已经确定，不再以写论文为由扩张。** 没有运行 ProLLaMA 两配方比较，它不是完成本次描述性 operating-point 研究的必要条件。原 R227 配方与[作者 Quick Inference 配方](https://github.com/PKU-YuanGroup/ProLLaMA)不同，故低识别结果不能声称模型上限；这是一项保留的外推限制，而非需要立刻重开的队列。本轮同样没有新增评分／稳定性矩阵、同源上下文模型或候选功能实测。若未来要声称某个生成物真实有功能，才需要对应序列的实验依据。

## 成文门槛与图的组织

本轮最有根据的贡献是：在同一可追溯生成总体上连接类别选择性、非冗余产出与经对照校准的顺序置信度，显示“有正行为信号”和“高绝对产率”能够给出不同的能力判断，并明确原生截断输出的解释。它没有借用给定变体的实验标签来证明生成物，也没有提出新的结构评价指标。独立成文可围绕这条已完成证据链组织；相对 ProteinBench、PDFBench、原 ZymCTRL 与实验研究的增量仍需清楚论证，不能仅把常见指标重新汇总。

当前主文以定量结果表开篇，并保留完整 29 类结果表；总体与方法流程放在 Methods。结果图依次连接识别与非冗余产出、配对结构置信度、连续分布、参考支持和原生完成状态，实际预测结构用于展示固定规则选出的例子。完整 profile 分配、长度支持与天然校准保留为补充证据。具体尺寸、位置和逐项对照由本地稿件的编辑记录维护，避免在投稿评估中重复一份版式清单。

英文论文、官方模板和可编辑图表已据实际结果编写，并按用户要求仅保留在本地稿件包中，原始预测、全尝试账目和 source data 已汇入带校验清单的本地交付；原始软件已公开。尚需处理的是作者贡献与全文批准、实际公开数据或审稿访问安排及投稿系统声明，不是自动开展另一轮补实验。五位作者及 ORCID 已核验；作者确认和永久 deposit 不能由可编译 PDF 替代。**完成的是一个有边界的计算证据包；刊物是否认为增量足够重要，仍是独立的编辑与审稿判断。**
