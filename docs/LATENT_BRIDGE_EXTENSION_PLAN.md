# 隐状态桥扩展合同

**日期：** 2026-09-08
**状态：** Phase A 已完成。当前七类任务和固定配方未显示隐状态桥优于普通显式交接；探索性结果与后续安排见 EXP-R2-238。首轮数字、PIN 与分析保持历史事实，不改判胜利，不重开 M2。下文保留冻结的 Phase A 配方，训练记录见 EXP-R2-236。
**权威：** 科学结论与关闭路线仍以 `docs/INTERPRETABILITY_TRANSFER_AUDIT.md` 为准。2026-09-07 首轮执行合同见 `docs/LATENT_BRIDGE_CAPABILITY_PILOT.md`。本文不更新 F/L，不进入 `STAGE_CONTRACTS`，不改变方向一→二→三。

## 目的

继续做方向一的能力探索，但把比较对象放回通道本身：冻结两端、只训短通道之后，隐状态桥是否比普通信息交接更有价值。随机冻结 donor 只回答来源归因，不能代替有桥／无桥，也不能代替隐状态／显式标签比较。

七类顶级 EC 答案本身很窄。把预测类写成规范 JSON 交给文本模型，是强且合理的对照，不能预设隐状态必胜。任何受训读出都会吃到注释监督；交接成功只说明该任务可通信，不证明原生生物学知识、自由功能解释或机制。

## 已定对照

Phase A 复用已准入的 prepared_v1 与预训练 donor_cache_v2：ProGen2-medium 内容位均值 1536 维，train 4096 / val 512 / 旧 test 1024，数据抽样 seed 仍为 20260907。桥与分类器都只在 train/val 上训练和选 checkpoint。旧 test 已查看，本阶段全部评分标为探索性；不能改 split 后称确认。

软桥复验沿用首轮冻结快照与训练 PIN（见 EXP-R2-236），不替换该快照。新训练 seed 为 20260908、20260909、20260910，全部保留；历史 seed 20260907 只作参考，不参与本轮选优。每条复验 20 epochs、batch 32、AdamW lr 0.001 / weight_decay 0.01 / betas (0.9, 0.999) / eps 1e-8、grad_clip 1、K=8、约 3M 可训练、chat / bfloat16 接收端，按验证集答案 token NLL 选最佳。

| 通道 | 可训练规模 | 训练目标 | 选模 |
|---|---|---|---|
| 软桥 K=8 | 与首轮相同，约 3M | 答案 token NLL | 最小 val NLL |
| 线性头 | 10,759 | 七类交叉熵 | 最小 val CE |
| 同预算 MLP 头 | 2,999,999 | 七类交叉熵 | 最小 val CE |

显式交接是新代码，必须先通过测试和不超过 32 条训练集记录的接口门，提交独立 PIN 后再 freeze；不得把新代码偷换进正在使用的软桥快照。输入同为冻结 LayerNorm 处理后的 1536 维均值。线性头为 1536→7；MLP 头为 1536→1943、GELU、1943→7。头用 FP32、只做类别交叉熵，沿用上述 20 轮、batch、AdamW 参数、梯度裁剪和三个 seed。三个 seed × 两种头在同一次训练调用中顺序完成，训练时不加载接收端。评估另开，先核对完整的头×seed 清单及 checkpoint 与该清单、实际输入的身份绑定，再消费全部固定 checkpoint，用同一 Qwen2.5-0.5B-Instruct 把预测类写成与首轮相同的规范 JSON。生成器只看见预测类，以及列出全部合法类别的指令，不看见序列、金标签或原记录；列出合法类别不是泄漏。接收端冻结。接口门用七种人为发送标签检查格式跟随，不是金标签能力。

每个 seed 分别报告头直接准确率、接收端端到端准确率、全部 attempt 的标签保留率、引入／纠正错误与 2×2 计数。非法 JSON 计错，不丢分母。主指标仍是全部 attempt 的 class 准确率；macro-F1、support、valid JSON 为辅助。每个 seed 做四项探索性差值：软桥减去线性直接、MLP 直接、线性交接、MLP 交接。家族配对 bootstrap 5000 次、seed 20260907、记录加权、95% 百分位区间，不作多重校正，不设确认 PASS，不按 test 挑 seed 或头。三 seed 均值与范围只作描述；同一 1024 条不能复制三次当作 3072 个独立样本。软桥优化 token NLL，头优化 class CE，且固定解码计算量不同，因此不声称只隔离了一项机制，也不声称总算力相等。

## 数据与统计边界

同一资格筛后 14,453 条。cap 外 8,821 条中有 8,413 条属于旧 cap 已见家族。严格排除旧 train/val/test 的全部 728 个家族与 4,905 个重复组后，剩余 408 条／250 个家族；若保留原 split 的 holdout，只剩 181 条／89 个家族，EC1–7 为 37、55、50、22、15、1、1。家族单位总数不是不够，但 EC6／EC7 各 1 条，不能做可靠逐类结论。整份 20k 已在 D3.g stage 35 做过检索（stage 36 未跑），未被本试验评分也不等于全新独立证据。

后续新评估候选是完整 Swiss-Prot（约 57 万条，当前 non-IEA 资格约 21.6 万，只抽过 20k）。若启用，必须另建队列，相对旧 20k 完整池重新做家族与近重复隔离，不能只凭不同 accession 或现成组名断言隔离：现有 family/dup 是池内连通分量编号，独立抽样后的同名组不可比较。须以旧池的原始 Pfam 标识和序列作参照，再测量残余同源；现有筛查不保证排除所有远缘同源。该队列尚未执行。即便新抽，也不能保证排除蛋白语言模型预训练语料，更不是湿实验新证据。现成带完整 EC 的酶序列可支持更细类别或反向任务的可行性调查，但与 ZymCTRL 训练分布不独立。

## 后续准入

科学运算只用现有一张 H200；L20 空闲卡仅接口。必要且有证据才扩容。不安装 pod 依赖，不持久化 pod 名。一律走标准冻结与外部包装器。

若分类器强而软桥弱，先区分读出、优化与信息压缩，再小范围试 K、顺序分箱或解码容量。若两者都弱，优先数据、表示与任务，不盲目扩大接收端。Phase A 属于前者：同一冻结表示上线性头可读出更多类别信息，下一步应区分读出、训练目标与 family shift，而不是先扩接收端或重开 M2。已冻结 checkpoint 上的 512 条 val 自由解码、分类头直接分数、class 数字与其余 token NLL 分解已按独立 PIN 在新 H200 快照完成，并经逐记录复核（EXP-R2-239）。三个 seed 的桥在 val 上也低于两头；JSON 均有效，几乎全部残余交叉熵集中在类别数字。较小的整体 token NLL 不代表类别已可靠预测，但这也未证明数字重加权或换桥结构能修复差距。val 与 train 家族重叠且参与过选模，不是独立泛化证据，也不能据其与旧 test 的差异定位 family shift 的因果贡献。更细 EC、多属性输出、以及语言→蛋白 soft-prefix，另立协议并先做真实接口门；条件似然或生成格式合格不等于功能验证，目前仅有 EXP-R2-237 的机械软输入验证，分箱、新队列和完整反向 M0 尚未执行。不列内部层或电路干预，不重开 M2。
