# Generation failure confirmation

Frozen 2026-09-23 before new scientific generation. This follow-up separates format, stopping and profile recognition at the native unlabelled operating point; it does not measure function or establish biological completeness. Existing 800-attempt ledgers remain the primary generation evidence. The confirmation is exploratory and smaller.

## Residue budget and outcomes

Run 64 attempts each for ProLLaMA Stage 1, ProLLaMA Stage 2, ProGen3-112M and ProGen3-3B. Native prompts are `Seq=<` and `<bos>1`, respectively. Use temperature 0.85, top-p 0.95, top-k 50, repetition penalty 1, batches of eight and seed 20260923 plus batch index. ProGen3 preserves the official generator's minimum of two generated tokens. Seeds identify independent draws; equal seeds across models do not imply paired sequences.

Stop each attempt independently on the first native terminal, model EOS, or token crossing 400 canonical prefix residues, with a separate safety cap of 1024 new tokens. Preserve raw decoded output and exact generated token IDs. A multi-residue token may cross the residue cap: retain it and report overshoot, rather than editing the distribution or claiming exact equal lengths. Do not constrain the alphabet or force a minimum residue length. Formatting failures may persist until the safety cap; report them separately. Report the actual stop reason and the residue count, not an inferred budget hit from absent delimiters.

Measure orthogonal fields: empty raw output, empty canonical prefix, invalid native format, native terminal observed, model EOS observed, native-format complete, and profile recognition of the canonical prefix. Native-format complete requires a nonempty canonical sequence followed by `>` for ProLLaMA or `2<eos>` for ProGen3. The first native terminal bounds the sequence; historical raw text after it is preserved but excluded from the sequence-format assessment. A prefix with a Pfam hit remains prefix evidence if censored. Report complete-with-profile and complete-without-profile counts, all-attempt Pfam recognition, and profile-bearing near-duplicate groups using the existing residue-shingle grouping policy. Proportions use all attempts as denominator with Wilson 95% intervals; conditional denominators, if added, must be named. No Pfam annotation means unavailable, not zero.

Use the existing frozen Pfam-A database and gathering thresholds. An existing ledger without exact token traces supports native terminal and format classification but cannot establish whether an absent terminal was caused by a token budget; mark that stopping reason unknown. ProLLaMA Stage 2's bare `Seq=<` condition is outside the instruction prompt used for its supervised tuning. Any reduction is specific to this operating point and cannot establish a general loss of generation capability.

### Bounded attention/MLP refinement

The admitted tensor inventory makes embedding/head exchanges exact no-ops. The next intervention is limited to two crossed settings across all layers: Stage 1 attention with Stage 2 MLP (`01`) and Stage 2 attention with Stage 1 MLP (`10`). Digits are ordered attention/MLP. Embedding, head and norms remain at their identical checkpoint values; each complete attention or MLP submodule is exchanged, without changing tokenization or scoring. Native reconstructions `00` and `11` must reproduce their unmodified checkpoints exactly before a hybrid is evaluated. The already running FP32 native measurements supply these endpoint outcomes; their coarse labels `000` and `111` map to `00` and `11`.

Freeze 32 families from the native eligible assay list with NumPy seed 20260923, sorting family identifiers by their string representation before a uniform permutation. Sort the selected families by the same rule, then sample one assay uniformly from each family's sorted assay identifiers with the continuing generator. Selection consults only identifiers and eligibility, not effects or model scores. Preserve each selected assay's original 128-variant draw. The frozen panel contains 32 assays, 32 families and 4,096 variants, with SHA256 `4110a38b5aeabbb5d552bbed3f1788adc888681386977b9035e79a51b7d1f15b`; its manifest binds the full source cohort, native eligibility receipt and checkpoint inventory. No family is replaced after undefined or unfavorable results.

Both crossed settings use singleton FP32 mutation scoring with TF32 disabled, and the same 64-attempt generation recipe, residue budget, seed batches and Pfam annotation as the FP32 native endpoints. Reuse native mutation rows only on the frozen panel; reuse their generation attempts without claiming new observations. Run only these two hybrids after the higher-priority analyses release compute. Do not extend the panel, tune generation or add layer sweeps based on outcomes.

For each endpoint, report attention and MLP marginal effects, both conditional effects for each block, and interaction `Y11 − Y10 − Y01 + Y00`, along with the native Stage 2-minus-Stage 1 contrast. Mutation intervals resample the common defined families; generation intervals jointly resample matched seed batches across all four settings. Off-distribution hybrid incompatibility and the small generation sample remain explicit limitations.
