# 金融评价指标是否适合方向一

**评估日期：2026-09-05。** 判断是：有值得借鉴的统计思想，但当前论文不宜直接加入一组金融名称。最可能增加信息的是跨类别或家族的**标准化配对增量**，以及预先定义的**基线校准回归**；Sharpe* 和 DSR 更适合评估经过多次尝试后选出的方案。以下建议覆盖[完整方向一](../summary.md#方向一比较模型具有什么能力)，不改变已完成实验的主终点。

已有研究确实把均值与方差共同优化推广到一般强化学习和多臂老虎机，但所核查论文的实验例子主要仍是投资。AlphaSharpe 使用 LLM 搜索金融指标，评价的也是金融收益，并不是用 Sharpe 衡量语言模型或蛋白模型本身。本轮尚未检出将这些指标直接用于蛋白生成生物证据评价的原始论文；这只是检索结果，不是不存在相关工作的证明。[Tamar 等，2012](https://arxiv.org/abs/1206.6404)、[Khurshid 等，2025](https://doi.org/10.1007/s10994-024-06680-2)、[AlphaSharpe](https://arxiv.org/abs/2502.00029)

## 定义与本任务中的对应关系

令 d 为同一评价单位上的模型测量减参照测量，Y 为模型测量、X 为基线测量。这里的“收益”只能是明确命名的测量增量，不能直接解释为生物知识。

| 指标 | 原始定义及可对应变量 | 必需条件与可能增加的信息 | 当前建议与未来适用情形 |
|---|---|---|---|
| Sharpe | `S = E[d] / SD(d)`；例如类别内加权的 original−shuffle CA-pLDDT 差，再跨类别标准化 | 分母必须是**差值**的离散程度；需固定单位、基线和权重，方差非零。概括平均增量相对于类别间异质性的大小 | 可作为探索性标准化配对效应；同时报告原始差值及分布。未来用于同任务、同队列方案比较 |
| Sharpe* | 本文按已确认含义使用 `S* = E₀[maxⱼ Ŝⱼ]`（j = 1,…,N），即零信号下多次搜索可期待的最大 Sharpe 基准 | 要知道候选搜索范围、候选统计量分布及依赖；不是单次生成的生物学对照 | 当前不补造；未来完整记录模型、配方、种子及选择规则后，估计选择造成的乐观程度 |
| DSR | `DSR = PSR(S*)`，把上述选择基准放入考虑样本长度、偏度和峰度的 Sharpe 推断 | 需要有效独立观测、全部候选及候选间方差/相关性；回答优胜者是否超过搜索偶然性 | 当前不作为新增验证分数；未来用于明确的方案搜索，并检查校准与保留集表现 |
| beta | 金融中 `β = Cov(Y,X)/Var(X)`；这里可拟合模型分数对基线分数的斜率 | 配对单位、量纲和基线有意义；回归形式、分组依赖与支持范围明确。反映共同变化或敏感性 | 仅作为描述性校准系数；未来按家族划分拟合/验证集，检查长度、参考覆盖等因素 |
| alpha | CAPM 中风险调整后的截距；一般回归为 `Y = α + βX + ε` 的截距 | 必须声明基线及零点；截距随中心化改变。可描述指定基线未解释的平均偏移 | 不称“净知识”或机制。未来报告校准后偏移及留出误差，与原始配对差并列 |

Sharpe 的基础是差额均值与其标准差之比；在普通独立观测的单样本均值检验中，`t = S√T`。因此同一形式也可以是标准化效应，而不必引入金融含义。Jensen 的 alpha/beta 则来自特定资产定价模型；蛋白任务中的回归没有自动继承资本市场均衡解释。[Sharpe，1994](https://web.stanford.edu/~wfsharpe/art/sr/SR.htm)、[Jensen，1968](https://doi.org/10.1111/j.1540-6261.1968.tb00815.x)

## 对当前结果能增加什么

标准化有助于区分“增量较大但类别差异明显”和“增量较小但较一致”。不过，极小且稳定的正差也可能产生很大比值；对于零基线的单个二元成功事件，均值/标准差只是成功率的单调变换，不能补出多样性或完成度信息。这是由公式得到的判断。当前已经报告类别分布、绝对产率和非冗余计数，新增比值只有在回答明确的稳定性问题时才有价值，不能据此重排不同原生任务的模型。

DSR 的标准表达为

$$
\widehat{DSR}=\Phi\!\left(\frac{(\widehat S-S^*)\sqrt{T-1}}{\sqrt{1-\widehat\gamma_3\widehat S+(\widehat\gamma_4-1)\widehat S^2/4}}\right),
$$

其中 `γ₃` 是偏度，`γ₄` 是普通峰度；`N` 是用于构造选择基准的独立候选数，和观测数 `T` 不同。它是依赖模型假设的推断量，不是知识存在的概率。[PSR 原文](https://www.davidhbailey.com/dhbpapers/sharpe-frontier.pdf)、[DSR 原文，式 2 与附录 3](https://www.davidhbailey.com/dhbpapers/deflated-sharpe.pdf)

当前条件结构分析的重复单位是 14/15 个类别；不能把合计 2,692 条预测记录、残基或 bootstrap 次数当成独立 `T`。小类别样本的偏度、峰度不稳定，类别内又有抽样权重和重复关联；ProGen3 则只有一个原生任务，应沿用其序列组单位。现有两个冻结主对比已有预定多重性处理；若历史搜索总数未知，不能用当前模型数、论文数或日志条数猜填 `N`。Lo 的推导也表明，依赖结构会改变 Sharpe 的统计性质。[Lo，2002](https://alo.mit.edu/publications/page/18/)

alpha/beta 更有潜在解释增量，但也最容易误读：若固定 `β = 1`，按同一权重估计的截距正是现有平均配对差，未新增测量；放开斜率才会描述不同基线水平下的变化。即使加入长度、组成或参考覆盖，回归残差仍可能包含遗漏因素、测量误差及非线性，不能直接归因于机制或“纯知识”。无参考命中也不能填成零相似度来拟合。

## 对完整方向一的处理建议

ProteinGym 和 MegaScale 已有模型减简单基线的配对比较，可优先考虑按家族、设计 series 或自然 cluster 汇总的标准化增量；不同支持集仍须分开。条件生成采用类别单位，原生无条件生成采用序列组。上下文信息、联合模式、同源上下文和长程影响实验应保留各自区块、目标组及字符/残基定义；标准化不能修复 tokenizer 单位不一致、低重叠层失败或测量资格不通过。

当前稿维持既定终点。若未来确实要比较生成策略的稳定性，先固定共同任务、实际目标量与成本/失败处理，再预先指定一个标准化辅助量或一个校准回归，保留独立家族验证；只有发生明确的多方案择优且完整记录候选时，才评估 Sharpe*/DSR 是否优于现有分组重采样与多重性控制。这样检验的是新增统计信息，而不是给已有结果更换名称。

**检索边界。** 本轮使用 Sharpe/deflated Sharpe 与 protein design、protein language models、generation evaluation、classification、CIFAR/MNIST、non-financial RL 等组合，核查原始金融论文、作者稿及正式 ML 论文。金融交易结果、泛化理论和蛋白评价直接迁移分别判断；未做系统综述，也未运行或新增任何实验。
