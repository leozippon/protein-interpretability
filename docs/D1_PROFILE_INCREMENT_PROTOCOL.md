# Profile increments and failure conditions

This protocol freezes two exploratory Direction-1 follow-ups before their execution on 2026-09-23. Existing assay summaries already motivated the questions; this is not an independent confirmatory replication. The endpoint is incremental prediction of experimentally measured effects, not identification of a parameter mechanism or proof of biological information absent from all profiles.

## Mutation-level profile increments

Retain aligned mutation identifiers, measured effects, scalar profile scores and model mutant-minus-wild-type scores, with source digests. Use the context experiment's label-blind 128-variant draws and explicitly report its context-feasible support; do not substitute these estimates for the historical 1,000-variant assay summaries. Analyze each available model and context condition separately.

Within each assay, report Spearman correlations of model/profile, model/effect and profile/effect. Residualize both model ranks and effect ranks on an intercept and profile ranks, then correlate their residuals. Undefined correlations, including constant scores or vanishing residual variance, remain missing with counts. Partial rank correlation controls only the scalar profile score and a linear relationship in rank space; nonlinear profile relationships and unmeasured evolutionary properties can remain.

For supervised incremental prediction, leave each existing 50%-identity wild-type family out in turn. Fit ordinary least squares on profile alone and profile plus model, with equal training weight per family and equal assay weight within family. Represent predictors and outcomes as within-assay standardized ranks so heterogeneous experimental scales are comparable. Test predictor ranks use the unlabeled held-out assay panel (a declared transductive normalization); test outcome ranks enter evaluation only. No coefficient, hyperparameter, or score orientation uses held-out outcomes. No tuning is performed. Report the held-out Spearman difference and reduction in standardized-rank mean squared error, alongside each predictor's performance. A negative profile coefficient is retained rather than repaired using held-out labels.

Average assays within family, then families equally. Use 2,000 family-bootstrap replicates and percentile 95% intervals. These intervals condition on fitted cross-validation predictions; they do not refit the training procedure in each replicate and therefore do not quantify training-set variation. Family identity clustering reduces close-homology leakage but does not establish remote-superfamily disjointness. Report each arm's original support and any explicitly labeled common-support sensitivity separately.

For the completed context-vector files, run `scripts/transfer/analyse_profile_increment.py --vectors-only --common-support` with one `--vectors` argument per arm, plus the required input/output paths. The report retains native-support analyses and adds the assay intersection only after exact agreement of ordered mutations, WT/family identities, draw digests, profile scores and measured effects; a mismatch fails explicitly. Both supports retain assay, family and variant counts, with exclusions enumerated by arm. An empty intersection is reported as undefined without correlations. Selected contexts and native encodings remain model-specific, so this sensitivity does not impose identical context sequences across models. The statistical procedures are unchanged and held-family predictors are refitted on the intersected panel.

## Protein-level failure conditions

Use retained historical assay Spearman scores, requiring exact mutation-digest agreement with LOOKUP. The current ProGen3 source is R242's residue-only scored-span remeasurement. Each arm retains its own eligible assay support. The initial roster comprises ProtGPT2, the five ProGen2 rungs, the two ProGen3 rungs, the Llama-2/ProLLaMA ladder and ProteinGLM when its retained score payload is available.

The response is assay MODEL−LOOKUP Spearman. Covariates are log10 effective homolog depth, maximum observed homolog identity normalized by query length (percent), mean smoothed profile entropy (nats per residue), and log10 wild-type residue length. Entropy uses the same retained weighted column frequencies, background frequencies and pseudocount weight as LOOKUP; normalize each column after smoothing and average its Shannon entropy. These are properties of the searched external corpus and retained alignments, not certified training-set coverage. Search hit-list saturation censors depth; report saturation separately. Observed sequence counts and supported-column fractions are descriptive diagnostics rather than redundant regression terms.

Define low/middle/high covariate strata using tertiles across the complete frozen wild-type catalogue, without model outcomes, and reuse the same cut points for every arm. Family-average the assay response within each stratum and bootstrap families. Also fit a joint regression to family means of response and covariates, giving families equal weight; standardize covariates on the observed arm support and add one exploratory depth-by-entropy interaction. Report the design condition number and predictor correlations, coefficients per standard deviation, family-bootstrap intervals and failed bootstrap fits. Do not select or drop predictors based on statistical significance. An ill-conditioned design is reported as a limitation; a rank-deficient design fails explicitly. Intervals are exploratory and unadjusted for multiple comparisons.

Raw model and LOOKUP correlations accompany each stratum because their difference alone can associate with a covariate through either channel. These analyses identify observable conditions associated with relative performance; they cannot establish why the model's internal computation fails or support a universal capability tradeoff.
