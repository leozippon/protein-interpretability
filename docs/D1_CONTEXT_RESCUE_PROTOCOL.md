# Homolog-context mutation rescue diagnostic

This prospective diagnostic asks whether providing an external homolog changes mutation ranking within each checkpoint. It does not identify whether evolutionary information was absent from pretrained parameters, and a negative result does not establish that family information cannot be used under another interface.

## Frozen support and controls

Use the existing external UniRef50 ProteinGym catalogue, profile and original 1,000-variant draws (seed 20260807 plus original assay index), binding every original mutant digest. Select up to 128 variants without labels using a second uniform permutation at seed 20260923 plus original assay index, then retain their original order. This second draw is necessary because the original sampling function returns selected rows sorted by CSV position. These diagnostic results have their own support and do not replace historical full-draw estimates.

Provide one ungapped aligned homolog fragment from the existing DIAMOND search, covering at least 80% of the target query and carrying 30% to less than 80% identical residues relative to the full query. Rank eligible fragments by descending alignment bitscore and subject identifier; retain the first feasible matched pair. Excluding near copies reduces direct target copying, but it does not exclude homologous pretraining exposure. Fragment context is explicitly distinct from a complete sequence or an MSA.

Unrelated candidates come from homolog fragments of different 50%-identity WT families, with subject identifiers absent from the target's detected hit list. Screen the nearest 256 candidates by residue-length distance, require exact rendered token-count equality with the homolog, rank by amino-acid composition distance, and require longest common substring below 10 residues against the target. Absence from the detected hit list is an operational unrelated control, not a proof of evolutionary nonhomology. Selection uses no experimental effects. Candidate pools and selected sequences are retained.

Evaluate no context, unrelated context and homolog context using the same full WT and mutant targets. A 1,024-position budget applies to the entire packed sequence. Never truncate targets or contexts. Exclude and enumerate assays with no eligible matched pair or an over-budget target; support may vary by tokenizer. Model comparisons require an explicit intersection, whereas within-model condition comparisons are paired by construction.

## Scores and inference

Reuse the stage-46 native packed-item interfaces, separate tokenization of each item and existing target-only residue spans. Score sum log likelihood over exactly that span, excluding rendering markers. For each condition retain mutant minus WT log likelihood, experimental effect, profile score, mutation identifiers and WT target likelihood. Compute Spearman correlations within assay; the primary contrast is homolog minus unrelated Spearman. Report MODEL minus LOOKUP on this same diagnostic draw, and WT homolog minus unrelated target likelihood in nats per scored token within each model.

Two secondary paired contrasts compare homolog minus no-context and unrelated minus no-context Spearman on the same assays, with the same family aggregation and interval procedure. These distinguish improvement over the native baseline from recovery of degradation induced by unrelated context. They were added to the analysis specification before completed scoring files were analyzed; they do not change scoring, the primary contrast or its bootstrap seed. Report undefined contrasts when either constituent correlation is undefined, rather than substituting a zero effect.

Analyse all retained assays and the predefined selected-homolog identity below 50% and local longest-common-substring below 10 residues strata. Report assay and family counts. Average assays within existing 50%-identity WT families and bootstrap families with 2,000 resamples, seed 20260923; apply the repository minimum-unit rule for intervals. Strata are conditional on fragment selection and are not an unbiased census of homolog availability. Null intervals do not establish equivalence. In particular, positive WT likelihood and unresolved mutation-ranking differences are not proof of a zero ranking effect.

Use float32 model scoring with TF32 disabled for ProteinGLM and the ProLLaMA stages. ProGen3 requires its supported reduced-precision kernel; record this limitation and retain batch/single checks. On the first admitted assay in each condition, compare WT and two mutants separately against the batch; refuse differences above 0.02 nats per scored token or 0.001 nats in either mutant minus WT score. A failed arm may be rerun at batch size one, retaining the failed receipt and the changed batch setting. No cross-tokenizer likelihood magnitudes are compared. The initial panel is ProGen3-3B, ProteinGLM-7B-CLM, ProLLaMA Stage 1 and Stage 2. The run is exploratory and the diagnostic scale is frozen before scoring.
