# Document index

`INTERPRETABILITY_TRANSFER_AUDIT.md` is canonical for findings, limitations, retractions and the current scientific plan. `summary.md` at the repository root is the user-facing overview. This index says only what each document is for and whether its work is open or closed; for the scientific status of anything named below, read the audit's §0 rather than inferring it from an entry here.

A Direction-1 campaign is normally two documents: a protocol frozen before its data existed, which keeps its pre-data wording, and a separate results record carrying the admitted outcome. Both are listed, and a campaign with no separate results file says so.
