# Frozen-representation mutation readout diagnostic

This protocol specifies the frozen-representation readout experiment. The original five-model study is complete; the subsequently authorized full-available-panel extension is governed by the expansion addendum below. Its purpose is to test whether a supervised predictor of frozen representations improves prediction of measured mutation effects beyond equally supervised sequence/profile and likelihood controls. The [canonical audit](INTERPRETABILITY_TRANSFER_AUDIT.md) remains authoritative for the scientific plan and admitted findings. This document governs the new experimental recipe; it does not report results.

For example, a model's likelihood may rank an enzyme mutant below another mutant while a predictor fitted to its internal representations reverses that ordering and agrees with measured activity. Improvement on families absent from readout training would support a limitation of the specified likelihood readout. However, the predictor receives experimental labels from other families. Improvement over unsupervised likelihood alone cannot distinguish a better representation readout from the benefit of new supervised information; the equal-label controls below address that comparison.

## Representation and likelihood measurements

Freeze every model parameter and disable dropout. At the output of its middle transformer block and final transformer block, collect both the arithmetic mean over target residue tokens and the last target residue-token state. Middle means the block after half the stack has been traversed, rounded upward; retain the exact zero-based hook indices. Use block outputs before any separately applied final normalization and state that convention in the manifest.

Subtract the corresponding WT vector from each mutant vector separately for each of these four blocks of features. Pool all residue tokens, excluding native rendering markers, EOS, BOS, context and padding. For ProteinGLM, include its first residue in representation pooling even though the retained native likelihood interface scores residues 2 through L. Record the pooling and likelihood spans separately. A token can encode more than one residue in the Llama tokenizer; the mean is token-weighted, not residue-weighted, and mutant/WT token grids need not align.

These choices accommodate causal models. The state before a changed token cannot contain a response to that mutation; the state at the mutation cannot use the subsequent suffix. The last residue state and whole-target mean provide complementary summaries after some or all of that suffix has been processed. They are bounded summaries, not a complete census of information in every activation.

Measure mutant-minus-WT native residue-span summed log likelihood in the same forwards and retain it as scalar M; preserve the external profile score as P. Do not change scoring conventions to optimize agreement with effects. Retain full-dimensional vectors so deterministic compression can be replayed without model inference. Use FP32 for the Llama lineage and ProteinGLM with TF32 disabled, and record ProGen3's required reduced-precision kernel. Exclude no difficult assay silently.

Before production, qualify batching on H200 using three label-blind assays: shortest, median and longest eligible maximum packed target lengths, measured over WT and the original complete variant draw, breaking ties by assay identifier. Score WT and the first three retained variants in each smoke assay. Compare the first two mutant-minus-WT likelihood scores against individual forwards, requiring maximum absolute disagreement at most 0.001 nats. Compare each of the first two mutant-minus-WT representation vectors, concatenating the four full feature blocks before compression, against individual forwards: require relative L2 disagreement at most 0.001 (0.1% of the single-forward mutation-vector norm). Retain zero-denominator cases explicitly; a nonzero discrepancy against a zero reference cannot pass a relative tolerance. These thresholds are fixed before inspecting smoke results.

Retain raw-state and mutation-vector drift measurements and every failed receipt. If an arm fails either threshold, select batch size one for that entire production arm before production begins; do not switch individual assays silently. Retain first-two-variant checks during production and fail explicitly if a batched arm exceeds the thresholds. These checked examples diagnose batching sensitivity and do not certify numerical accuracy for every untested variant or against a higher-precision reference.

Before production, local interface checks selected singleton extraction for the entire ProGen3 arm. A discovered batch-row-dependent sequence-ID assignment was corrected to the native independent-sequence value zero, but post-correction batch-versus-single disagreements still exceeded the likelihood tolerance. Thus the semantic repair does not establish numerical batch invariance; the remaining cause is unresolved. H200 qualification retains the batched diagnostic and a singleton confirmation, and ProGen3 production remains batch size one.

The H200 length-stratified smoke also exceeded the fixed mutation-vector relative-L2 tolerance for the Llama-2 parent (maximum 0.00112228) and ProLLaMA Stage 1 (0.00109461). These finite qualification maxima have no sampling interval. Before inspecting readout outcomes, production was fixed at batch size one for the parent and both ProLLaMA stages; Stage 2's observed maximum was 0.00093512, but it uses the same singleton setting for paired lineage comparisons. ProteinGLM alone uses batch size eight: its maximum observed likelihood-delta discrepancy was 0.00002288818359375 nats and mutation-vector relative-L2 discrepancy was 0.00004553885254709817 across all three smoke assays. These complete-smoke maxima are verified in `results/transfer/readout_20260923/smoke_admission.json` (source archive SHA256 `8a30b355d094b3d71c4e253f321ce1371ecab41fb025edc7f5750975e8c441da`), and both satisfy the unchanged 0.001 gates. The thresholds remain unchanged. Smoke runs retain their independent singleton references, and production retains the required per-assay repeat checks. These observations do not guarantee accuracy for unchecked variants.

## Equal-label predictors and held-family evaluation

No assay labels from an outer held-out family may enter coefficient fitting, scaling, regularization selection, model selection or score orientation. Assign complete families to five deterministic outer folds using a seeded permutation of sorted family identifiers and round-robin assignment, with seed 20260923. Save the explicit assignment and reuse it for every predictor and model on common support. Within each outer training partition, assign its families to four inner folds by the same deterministic procedure for tuning, with seed 20261023 plus the zero-based outer-fold index. Thus all assays of each WT family remain together at both levels. Identity clustering reduces close-homology leakage but does not guarantee remote-superfamily separation or exclude overlap with pretraining.

Convert measured effects to within-assay standardized average ranks, using the population standard deviation. Training-assay ranks are training targets. Inner-validation and outer-test targets are transformed only for scoring held-out predictions. Constant targets are explicitly undefined for Spearman and separately counted. Convert P and M to within-assay standardized average ranks; this uses the unlabeled test panel and is a declared transductive normalization. It supplies no experimental effects to prediction.

Define sequence descriptor S from substitutions and sequences alone: counts of each directed amino-acid substitution in a 20 by 20 array, number of mutations, mean and population standard deviation of relative mutated positions, WT and mutant amino-acid frequency vectors (20 coordinates each), and WT residue length divided by 1,024. Positions are one-based position divided by WT residue length; a single mutation has position standard deviation zero. Validate every substitution against the WT. These descriptors expose simple mutation-identity, position and composition signals that representations might carry without an assay-specific biological computation.

Fit the following predictor sets on identical training labels and weights:

| Predictor | Features | Purpose |
| --- | --- | --- |
| P | Scalar profile rank | Supervised scalar-profile control |
| M | Scalar likelihood rank | Supervised likelihood calibration |
| P+M | Both scalar ranks | Reproduce the existing scalar-combination question under this new split |
| S | Sequence descriptors | Supervised sequence-only control |
| P+S | Profile and sequence descriptors | Profile-plus-sequence control without model likelihood |
| B | P+M+S | Primary sequence/profile/likelihood control |
| R | Frozen representation features | Standalone supervised representation readout |
| B+R | Control and representation features | Primary incremental-information test |

Also report raw P and raw M Spearman without fitting. No favorable scalar orientation may be selected using test labels. Every fitted predictor uses ridge regression with an unpenalized intercept and the same penalty grid, inner validation objective and label support. Give each training family equal total weight, each assay within a family equal weight, and each variant within an assay equal weight. Normalize training weights to sum to one. Fit feature means and scales on training rows with those weights; apply them unchanged to validation/test rows. Constant training features receive scale one. Repeat this fitting separately inside every inner split.

For feasible GPU fitting, project each of the four full representation feature blocks to 256 dimensions with a fixed seeded Gaussian matrix whose entries have standard deviation 1/sqrt(256), before train-fold feature scaling. Use seeds 20260923 through 20260926 in the declared layer/pooling order. Projection depends only on width and the recorded seed, never on labels or observed vectors. Concatenate all four projected blocks as R without selecting layers or pools from outcomes. This bounds the readout class and may discard useful signal; a negative result applies to this compressed linear readout.

Choose ridge penalty from {0.01, 0.1, 1, 10, 100}, in the objective weighted mean squared error plus penalty times squared coefficient norm. Minimize inner-validation family-equal standardized-rank mean squared error, breaking exact ties toward stronger regularization. Refit on all outer training families using that penalty, then predict outer-test families once. Retain selected penalties, fold memberships, per-variant held-out predictions and fitting failures. Nonfinite inputs or failed linear solves are explicit failures, not zero predictions.

Run one negative-control fit for B and B+R using labels permuted independently within each assay at seed 20269923 (the experiment seed plus 9,000). Both coefficient fitting and inner validation use those permuted labels; outer-test evaluation uses the untouched measured effects. Apply the same family splits and fitting procedure. This is a fitting-leakage diagnostic, not a permutation p-value or an exhaustive test of leakage.

Before readout outcomes are inspected, add two common-support split-robustness repeats with outer-fold seeds 20260924 and 20260925 alongside primary seed 20260923. Each uses its own inner-fold seed equal to outer seed plus 100 plus the zero-based outer-fold index. Keep projection seeds fixed at 20260923 through 20260926, so these repeats change family splits only. Keep all other feature, target, tuning and evaluation choices unchanged. Native-support sensitivity and the label-permutation control run at the primary split seed only. Save and report all three split assignments and outcomes; do not select the best split. These are robustness checks on the same biological cohort, not independent replications.

## Contrasts and uncertainty

For each model, the primary endpoint is the family-equal mean within-assay Spearman difference between B+R and B, on exact shared support. Average assays within family, then families equally. The paired secondary endpoint is MSE(B) minus MSE(B+R), in squared standardized-rank units; positive means improvement. Report standalone readout, scalar controls and raw likelihood/profile correlations alongside these contrasts. Also report paired R-minus-raw-M and B+R-minus-raw-M Spearman differences: these quantify practical changes from likelihood scoring, while B+R-minus-B addresses added prediction beyond the matched supervised control. Gains over raw likelihood alone are insufficient evidence of representation-specific value.

Use 2,000 paired family-bootstrap draws with seed 20260923 and percentile 95% intervals, honoring the repository minimum-unit rule. Compute each contrast on the same defined assay pairs and enumerate undefined statistics and family counts. These exploratory, pointwise intervals condition on fitted cross-validation predictions; they do not refit training or tuning within bootstrap draws and omit training-set and split variation. They are not adjusted for the five models and multiple secondary comparisons. Do not choose the best model and report it as a prespecified confirmation.

For common support, report each split seed's effect estimate and conditional interval, together with the minimum and maximum point estimates across the three splits. That range describes sensitivity to these splits; it is not an uncertainty interval or a substitute for independent replication. Do not impose an unmotivated threshold for a “substantial” repair. Quantify the effect sizes and their uncertainty; neither an interval crossing zero nor a small three-split range proves absence of accessible information.

A positive B+R increment supports accessible predictive information beyond the specified equally supervised controls and the specified likelihood readout. It does not show that the complete model contains a biological mechanism absent from richer profile features. A null or negative result does not show that representations contain no useful information: linearity, pooling, compression, label budget, assay heterogeneity and transfer to unseen families all limit this diagnostic. The text-parent arm and paired Stage 1/2 comparison help assess lineage specificity but do not isolate an objective intervention.
