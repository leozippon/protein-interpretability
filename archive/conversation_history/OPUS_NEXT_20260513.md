## 1. Diagnosis of Why Annotation Came Back Weak

The brilliant plan's A-1 gate was "≥ 25 of 38 triplets receive an
interpretable category (MI ≥ 0.1 nats on at least one biological label)".
The low-risk run measured MI against:

- amino-acid identity (20 categories)
- coarse chemistry (5-6 categories)
- source (real-lysozyme / random-UniRef50)
- positional bin

All four are *cheap* labels — derivable from sequence alone. They are not
the biological labels the gate was meant to test. The rich labels in the
brilliant plan were Pfam family, Swiss-Prot per-residue (functional / ptm /
domain / region / topology), and DSSP secondary structure.

The resource-coverage run (`32_universal_resource_annotation.py`)
demonstrates that the cohort the annotation actually used has near-zero
coverage of those rich labels:

- UniRef500: 0 / 452 Pfam-covered, 0 / 452 Swiss-Prot-covered, 1 / 452
  AlphaFold-covered.
- Balanced-200: 7 / 33 Pfam, 7 / 33 Swiss-Prot, 0 / 33 AlphaFold (and the
  Swiss-Prot hits are mostly uninformative chain/topology rows).

So the 0.001-nat result is a measurement of the wrong thing. It does not
falsify the universal-primitives hypothesis. It only says "low-level
sequence statistics do not separate the 38 triplets". That was already
expected — the triplets are *not* family detectors (source-selectivity
confirmed 38/38 weak/source-mixed for lysozyme-vs-random).

The right experiment is to measure MI on a cohort where the rich labels
exist for every sequence. Swiss-Prot satisfies this by construction.

## 2. The Single Critical R2 Experiment

### N-1: Swiss-Prot-anchored triplet annotation
- **Cohort:** 500 Swiss-Prot sequences sampled with stratified Pfam-clan
  coverage. Filter to length 100–400 to keep activation extraction
  tractable.
- **Activation pass:** extract per-residue activations for the 38 triplets'
  member features across ProtGPT2 v2, ZymCTRL v2, ProGen2-medium on this
  cohort. Top-100 firing positions per triplet.
- **MI labels (rich):**
  - Pfam-A family (per residue, from InterPro annotations already in
    Swiss-Prot)
  - Swiss-Prot per-residue category (functional, ptm, domain, region,
    topology, secondary_structure, chain) — same labels R1 already uses
    for SAE annotation
  - DSSP-3 secondary structure (from Swiss-Prot `STRUCTURE` annotations
    where available, else from AF2 structures for the small subset that
    has them)
  - GO molecular function (per protein, then propagated to residues in
    domain spans)
- **Gate:** ≥ 25 of 38 triplets show MI ≥ 0.1 nats on at least one rich
  label. Bootstrap CI on MI per triplet.
- **Acceptance outcomes:**
  - PASS (≥ 25 of 38): the brilliant-primitives thesis is back on track.
    Proceed to causal intervention (A-3) next week.
  - PARTIAL (10–24 of 38): a substantial subset is interpretable. Reframe
    R2 as "a subset of universal latent features maps to biological
    categories; the remainder represents uninterpreted statistical
    regularities" — still novel, still Nat Mach Intel scope.
  - FAIL (< 10 of 38): downgrade R2 to "cross-model conserved latent
    features (statistically significant, biologically uncharacterised)" —
    NMI methods paper.
- **Effort:** ~1 H200-day for activation extraction; ~0.5 day analyst MI
  computation.
- **File:** `Research2/scripts/33_swissprot_triplet_annotation.py` (new).

This is the only R2 experiment that materially changes the paper. Run it
first.

## 3. The Cheap R2 Fallback (Run in Parallel)

### N-2: 38-dim triplet basis as a discrimination representation
- **Question:** even without naming the triplets, do their activations form
  a useful sparse representation? If a 38-dim vector beats raw embeddings
  on a downstream task, the triplets "do something" usefully even if we
  don't yet have an interpretable name for each.
- **Tasks:**
  - Pfam-clan classification on a stratified Swiss-Prot test set (top 50
    Pfam clans by count).
  - EC top-class prediction (oxidoreductases vs transferases vs hydrolases
    vs lyases vs isomerases vs ligases vs translocases) on Swiss-Prot
    enzymes only.
  - Secondary-structure-fraction prediction (regression: α-helix /
    β-sheet / coil fractions per protein).
- **Baseline:** raw ESM-2 mean-pooled embeddings (same protein cohort, same
  CV split, same probe model).
- **Probe:** L2-regularised logistic / linear regression. Protein-level
  hold-out CV with Pfam-clan as the CV unit.
- **Gate:** triplet representation matches embeddings on ≥ 1 of 3 tasks
  (CI overlap acceptable). Beating on ≥ 1 is bonus.
- **Effort:** ~1 H200-day.
- **File:** `Research2/scripts/34_triplet_basis_probes.py` (new).

This provides a fallback positive R2 result independent of annotation
outcome. Even if N-1 falls in the FAIL bucket, if N-2 shows triplets are a
useful low-dim basis, R2 still has a publishable claim.

## 4. Null Hardening (Cheap, Should Just Do)

### N-3: 30-replicate permutation null
- **Action:** rerun the permutation null over the balanced-200 cohort with
  30 (not 3) shuffled replicates. Report mean and 99% CI of triplet count
  at each threshold.
- **Why:** the headline statistical claim is "38 triplets vs null=0". With
  only 3 replicates the upper CI on the null is essentially unbounded.
  Reviewers will demand more replicates. Adding them now costs nothing.
- **Effort:** ~0.5 H200-day (matrix-product correlation, not full forward
  passes).
- **File:** edit `Research2/scripts/27_universal_atlas_null_control.py`
  (existing).

1. **Drop the gene-level mechanism headline.** macro-AUC 0.5665, per-class

   head-to-head is dropped for this pass; the paper instead reframes
   IndelMissense as "the first interpretable protein-sequence indel

   all classes uniformly."

     with curated case studies. Not a competing scorer.
   - IndelMissense v1 dataset + baseline (6,649 records, AUC 0.7735) as
     the unique R1 contribution.

   the abstract to the three claims above; move all failed gates

   Diagnostics" so the paper is honest. No further R1 experiments needed.

## 9. Why This Plan Is Right

The brilliant pivot has not failed. **It has been measured against the
wrong cohort.** The 38 triplets remain the most striking single finding in
either project: three independently trained models, ~7,000 parameters each
in the matching layers, converge on 38 specific feature triplets at r≥0.9
with permutation null = 0. That is unchanged.

What the low-risk experiments revealed is that we cannot interpret those
triplets using a random-UniRef50 cohort, because random UniRef50 has no
annotation coverage. The fix is to use Swiss-Prot, where every sequence is
annotated by construction. This is one focused experiment, not a project
restart.

If N-1 succeeds, the R2 paper is a discovery-and-interpretation paper of
real significance. If N-1 fails and N-2 succeeds, R2 is still a clean
representation paper. If both fail, the R2 paper is a careful statistical
discovery paper documenting cross-model feature convergence — still novel,
still publishable, just less ambitious.

The honest landing remains: two methods-tier manuscripts in submission-
ready state by end of next week, with R2 having a real chance at the
brilliant interpretation if the right cohort recovers the signal. R1 is
done; freezing it now lets all attention focus on the R2 N-1 gate.
