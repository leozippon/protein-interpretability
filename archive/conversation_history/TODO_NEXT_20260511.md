# Next-Phase Research Plan (2026-05-11)

Successor to `TODO_NEXT.md` (2026-04-29). The previous Tier 0/1/2 pass has run
to completion; this document defines the next pass, given what we now know.

Guiding principle from the user: **make influential and beneficial studies**.

## 1. Honest Read of Where We Landed

### R1 (variant interpretation)
- **Pathogenicity scoring is solved by other groups.** AlphaMissense
  (ClinVar2000 AUC 0.9474, cancer holdout 0.9700) and gMVP (0.9369 / 0.9400)
  outperform SAE+LLR (0.9143 / 0.9193). We cannot win on the
  state-of-the-art-pathogenicity axis.
- **Variant-CV mechanism AUC 0.747 was inflated by gene-membership leakage.**
  Under protein-level CV (255 proteins held out), the SAE mechanism classifier
  drops to macro-AUC **0.5161** — close to random. This means the variant-CV
  result was largely "given a gene, recall its dominant mechanism", not "given
  a variant, predict its mechanism." The headline mechanism claim, as
  originally framed, is gone.
- **What survives.** Per-class signal at protein-level CV is asymmetric:
  - DN one-vs-rest AUC 0.483 (random)
  - GOF 0.521 (weak)
  - LOF 0.545 (weak but real)
  - LLR is worse than random on all three under protein-CV.
  The honest statement is: SAE features carry **gene-level mechanism
  signature**, plus a small variant-level LOF signal, plus a complementary
  pathogenicity signal worth +3 AUC points over LLR alone. That is the truth
  to build the paper on.
- **The unique capability.** SAE perturbation can score indels (deletion,
  insertion, duplication, delins). AlphaMissense, gMVP, ESM-1v cannot. T1-C
  achieved damage AUC 0.7734 on 6,649 supported indels. Below our previous
  0.85 target but useful and uncontested. **This is where R1 can be unique.**
- **ProteinGym remains a negative.** Signed-ensemble win rate 33.6% vs LLR
  (below the 40% threshold). Frame as scope, not failure.
- **Channelopathy clinical translation failed.** 62.5% concordance vs >=80%
  target. The dominant error is DN-on-KCNQ1 collapsing to LOF. We cannot
  claim clinical mechanism prediction.

### R2 (interpretable drug design via CLT)
- **Hook plumbing now works.** T0-A diagnostics pass; interventions
  measurably change logits.
- **Direct-effect feature selection + on-manifold TopK-aware steering** has
  been implemented and benchmarked. Result: **0/8 EC classes significant
  positive** under permutation tests. Selected leads (top-10 by curation)
  pass Pfam (9/10), CLEAN exact (9/10), and Foldseek TM>=0.7 (9/10), but
  generation-wide steering is not significantly above unsteered (Pfam OR=1.35,
  Fisher p=0.17; CLEAN exact 0.775 vs 0.775).
- **Metric stack is calibrated.** All six EC metrics separate real vs random
  UniRef50 with Cohen's d > 1.5. So the null is not a metric issue.
- **The R2 steering claim is no-go.** T2-D gate has been recorded.

### Manuscript state
- Three Nature Methods drafts exist (`manuscripts/nature_methods_initial_draft/`,
  `nature_methods_r1_variant_perturbation/`, `nature_methods_r2_circuit_diagnostics/`).
  This is the right pragmatic scope. Pushing higher is conditional on the
  experiments in Tiers 1–3 below.

## 2. Operating Guidelines (carried forward + new)

1. **No silent fallbacks.** Tier 0 of the previous pass enforced this; keep it.
2. **Protein-level holdout for any variant-effect claim.** Gene leakage is now
   documented in our own data.
3. **Every paper claim must survive an "AlphaMissense beats it on pathogenicity"
   sanity check.** Either the claim is on a metric where AlphaMissense cannot
   compete (indels, mechanism class, interpretability), or it is paired with
   AlphaMissense as the predictor and our contribution is residual.
4. **Bootstrap CIs and per-class metrics.** Per-class is what reviewers will
   demand.
5. **One commit per item.** Tag with the item ID (e.g., `[P3-T1-B]`).
6. **All new metrics calibrated against real-vs-random before use.** Established
   precedent from R2 T2-C.
7. **External-resource provenance is recorded.** Date staged, source, version,
   checksum. Already done for AlphaMissense, gMVP, ESM-1v, CLEAN, Foldseek,
   HMMER/Pfam — keep this standard for anything new.
8. **No wet-lab claim without a confirmed partner.** Decide partnership status
   before scheduling any wet-lab-dependent experiment.

## 4. Tier 1 — R1: Push the Indel and Diagnostic Stories (≤3 weeks)

These keep R1 within methods scope but maximise unique value.

### P3-T1-A: Scale indel mechanism prediction to ClinVar full set — [tier:1] [project:R1] [impact:UNIQUE NOVELTY] [effort:~3 H200-days] [file:`Research1/scripts/32_indel_full_scale.py` (new)]

T1-C used the supported subset (6,649 records). Scale to the full ClinVar
indel cohort with mappable protein context (target ~50,000–100,000 indels).
- Per-indel SAE perturbation signature, mechanism prediction.
- Stratify by indel class: deletion, insertion, duplication, delins, in-frame
  vs frameshift.
- Report pathogenicity AUC per class, mechanism-class distribution, and
  agreement with curated mechanism labels where available (Gerasimavicius,
  Badonyi).
- Compare against the only competitor that exists: SpliceAI, CADD, REVEL.

Acceptance: indel pathogenicity AUC by class, with the per-class breakdown
table. Target: in-frame indel AUC > 0.85; frameshift AUC > 0.90 (frameshifts
should be near-deterministic from sequence-position).

### P3-T1-B: Release an IndelMissense dataset and leaderboard — [tier:1] [project:R1] [impact:FIELD STANDARD] [effort:~1 week post-T1-A]

The indel-interpretation field has no standard benchmark. Package T1-A as:
- `data/indelmissense/v1/` — curated indel set with labels, splits (protein-,
  gene-, family-level holdouts).
- Reference implementation: our SAE+LLR pipeline as a baseline.
- Leaderboard scaffold (initially as a static markdown table, with a clear
  contribution policy).

Acceptance: dataset README, splits, JSONL, and baseline numbers published in
a repo. This is potentially the most-cited artefact of R1.

### P3-T1-C: SAE-residual diagnostic vs AlphaMissense — [tier:1] [project:R1] [impact:CORE STORY] [effort:~3 days] [file:`Research1/scripts/33_alphamissense_residual.py` (new)]

The available-baseline summary shows SAE-LR has Spearman 0.703 with
AlphaMissense on ClinVar — there is residual variance. Identify variants
where:
- AlphaMissense disagrees with clinical truth (false positives or false
  negatives by ClinVar review status >=2 stars).
- SAE-LR has the opposite call.

For these disagreement cases:
- Manually inspect SAE feature firing patterns at L31/L35 using the existing
  audit pipeline.
- Look for cases where SAE features identify a specific functional-site
  disruption that AlphaMissense's evolutionary score missed (or vice versa).

Acceptance: a curated table of ≥30 case studies showing one of three patterns:
(a) SAE catches AlphaMissense errors with biological explanation;
(b) AlphaMissense catches SAE errors;
(c) systematic disagreement that motivates a specific subclass of variants
where SAE adds value.

### P3-T1-D: Gene-level mechanism prediction — [tier:1] [project:R1] [impact:reframe] [effort:~4 days] [file:`Research1/scripts/34_gene_level_mechanism.py` (new)]

If protein-CV variant-level mechanism is at random (0.516), but variant-CV
(0.747) was largely gene-membership signal, then SAE features carry
**gene-level** mechanism information. This is a different but real claim.

- Aggregate SAE features per gene (mean firing, top-quartile firing, mean
  perturbation).
- Train a gene-level mechanism classifier: input = gene's aggregated SAE
  signature; output = dominant mechanism class.
- 10-fold CV with **gene-family** (Pfam clan) holdout — i.e., test on gene
  families absent from training.
- Compare against: gene-level baselines (Mendelian inheritance pattern,
  haploinsufficiency score pLI, gnomAD constraint metrics).

Acceptance: gene-level mechanism macro-AUC under Pfam-clan holdout. If ≥0.75,
this is the surviving mechanism claim; if <0.6, drop the mechanism narrative
entirely and rely on indels + complementary scoring.

### P3-T1-E: DN-specific feature discovery on KCNQ1 — [tier:1] [project:R1] [impact:rescue-clinical] [effort:~3 days] [file:`Research1/scripts/35_dn_kcnq1.py` (new)]

The channelopathy concordance failure is dominated by KCNQ1 DN variants
predicted as LOF. KCNQ1 forms tetramers; DN variants disrupt the assembly,
which is a localized structural mechanism.

- For the 10 curated KCNQ1-DN variants, compute SAE perturbation signatures
  at each of {L19, L23, L27, L31, L35}.
- For the 12 curated KCNQ1-LOF variants, do the same.
- Look for a small feature subset (≤20 features) that separates DN from LOF
  with macro-AUC > 0.75 *within KCNQ1*.
- Annotate those features manually: do they correspond to oligomerization-
  interface or pore-domain residues?

Acceptance: identification of a DN-specific feature signature on KCNQ1, with
biological annotation. If found, scale to KCNH2 / SCN5A / CACNA1C; if not
found within KCNQ1, the DN→LOF collapse is structural and we report the
limitation honestly.

### P3-T1-F: Targeted improvement on indel-mechanism AUC — [tier:1] [project:R1] [impact:performance] [effort:~5 days] [file:`Research1/scripts/36_indel_struct_features.py` (new)]

Push indel damage AUC from 0.773 → ≥0.85 by adding:
- ESMFold-predicted structural disruption (Δ pLDDT, fold-fragmentation
  metric) on a held-out indel sample.
- AlphaFold2 disorder prediction at indel locus.
- A learned ensemble of SAE perturbation + structural features.

Acceptance: ensemble AUC > 0.85 on protein-level holdout.

## 5. Tier 2 — R2: Pivot to Interpretable Function Prediction (≤3 weeks)

The steering claim is dead. R2's CLT features still have potential value as
a **representation** for downstream protein tasks. This is the realistic
maximum impact for R2 without wet-lab validation.

### P3-T2-A: CLT features as a downstream representation — [tier:2] [project:R2] [impact:CORE STORY for new framing] [effort:~5 H200-days] [file:`Research2/scripts/22_clt_downstream_eval.py` (new)]

For ZymCTRL and ProGen2-medium v2 CLTs, evaluate CLT features as input to a
suite of downstream protein-function tasks:
- **EC class prediction** (vs CLEAN, ESM-2, raw embedding baselines)
- **Pfam family prediction**
- **Secondary structure prediction** (CB513, TS115 standards)
- **Subcellular localization** (DeepLoc benchmark)
- **Stability change on point mutation** (FireProtDB / ProTherm subset)

Acceptance: CLT-feature linear probes beat raw embeddings on ≥2 of the 5
tasks with statistical significance. This becomes the headline of the R2
paper: "CLTs produce a sparse, interpretable feature basis that is at least
competitive with dense embeddings, and is structured by protein function."

### P3-T2-B: Universal protein-LM circuit atlas — [tier:2] [project:R2] [impact:methods-novelty] [effort:~1 week] [file:`Research2/scripts/23_universal_features.py` (new)]

Cross-model conservation has shown CKA 0.79 at L12 between ZymCTRL and
ProGen2-medium on lysozyme leads. Extend this:
- Compute feature-feature correspondence across {ProtGPT2 v2, ZymCTRL v2,
  ProGen2-medium} using the existing CKA + max-correlation pipeline.
- Identify the *universal* feature subset (features matched across all three
  models with correlation > 0.9).
- Functionally annotate these universal features via max-activating
  sequences and Pfam alignment.
- Compare against the model-specific features (those matched in only one
  model).

Acceptance: a list of ~50 universal protein-LM features with biological
annotations, deposited as `Research2/results/universal_features_atlas.json`.
This is the "universal circuit primitives of protein generation" story.

### P3-T2-C: Toxicity / dual-use feature detection — [tier:2] [project:R2] [impact:SOCIETAL BENEFIT] [effort:~1 week] [file:`Research2/scripts/24_toxin_detection.py` (new)]

A CLT trained on protein generators learns features that fire on toxin-like
sequences in the training distribution. Build a CLT-feature-based classifier
that flags toxin-like generations:
- Training data: ProtGPT2/ZymCTRL CLT activations on (a) UniProtKB-Tox
  known toxins, (b) random non-toxic UniRef50 controls.
- Test: held-out toxins from VFDB, ATDB; novel ZymCTRL/ProGen2 generations.
- Compare against an external baseline like ToxClassifier or simple
  embedding-based MLP.

Acceptance: AUC > 0.85 on held-out toxin detection from CLT features alone,
with at least one toxin family where a single interpretable CLT feature
acts as a near-perfect detector.

**Note on framing:** this is *defensive* AI safety — better detection of
dual-use generation. The wet-lab risk is zero (we never synthesize toxins);
the benefit is biosecurity.

### P3-T2-D: Mechanistic hallucination detection — [tier:2] [project:R2] [impact:safety/utility] [effort:~5 days] [file:`Research2/scripts/25_hallucination_detection.py` (new)]

Generative protein models sometimes produce sequences that look plausible
but are catalytically nonsensical (wrong active-site geometry, broken
folds). Detect these from CLT feature firing patterns:
- For 1000 ZymCTRL-generated EC class sequences, compute structural
  validity via ESMFold pLDDT + Foldseek to known templates.
- Build a classifier from CLT features → "structurally valid" label.
- Identify CLT features that fire on "broken" generations.

Acceptance: hallucination-detection AUC > 0.80 from CLT features alone on
held-out generations. Identification of at least 3 interpretable CLT
features that distinguish valid from invalid generations.

### P3-T2-E: Refused R2 framing decision — [tier:2] [project:R2] [impact:project-defining] [effort:1 hour]

After P3-T2-A/B/C/D, choose the R2 manuscript framing:
- If A and B both succeed: R2 becomes a "**CLT features as interpretable
  protein representation**" paper (Nat Methods strong; possibly Nat Mach
  Intel).
- If C succeeds independently: split into a second short paper on AI safety
  for protein generation (Nat Mach Intel / a top safety venue).
- If none succeed: archive R2 as a diagnostic methodology contribution,
  publish as a benchmark/protocol paper.

Acceptance: explicit framing recorded in `PROJECT_STATUS.md` with metric
numbers that justify it. Manuscripts updated accordingly.

### P3-T3-A: Rare-disease retrospective concordance study — [tier:3] [project:R1] [impact:Nat Med] [effort:~6 weeks, depends on partner] [file:`Research1/scripts/40_rare_disease_retro.py` (new)]

The most beneficial possible R1 outcome: prove that SAE-based mechanism +
indel prediction changes patient triage outcomes retrospectively.

- Identify a rare-disease consortium with both genome data and treatment
  outcomes (Undiagnosed Diseases Network, IRDiRC, Genomics England
  100K Genomes rare-disease arm).
- Curate ≥200 patients with known causal variant + known treatment outcome.
- Apply our predictor; compare predicted-mechanism therapy class against
  actual successful treatment.
- Target metric: ≥75% concordance between predicted strategy and
  retrospectively successful intervention.

Acceptance: a defensible Nat Med-grade retrospective concordance number on
a curated cohort. **Requires partnership.** If no partnership in 4 weeks,
drop this item.

### P3-T3-B: IndelMissense MAVE pilot — [tier:3] [project:R1] [impact:experimental validation] [effort:~3 months including wet-lab]

Acceptance: ≥10 wet-lab-validated indel mechanism predictions. **Requires

### P3-T3-C: Translational deployment as a web tool — [tier:3] [project:R1] [impact:public benefit] [effort:~4 weeks]

Build a public web service that accepts a variant (missense or indel) and
returns: AlphaMissense pathogenicity + SAE mechanism prediction +
interpretable feature attribution + indel structural prediction. Anchor it

Acceptance: web service deployed (e.g., as a Streamlit + FastAPI app), with
documentation, ≥100 example variants, and a manuscript describing it.

### P3-T3-D: Circuit-level enzyme retargeting (deferred from previous TODO) — [tier:3] [project:R2] [impact:Nature] [effort:~3 months including wet-lab]

Carry over from `TODO_NEXT.md::T3-B`. Conditional on P3-T0-C (wet-lab

## 8. Three Honest Outcomes to Pick From

After Tier 1 and 2 complete, the project will land at one of three places.
Plan for each.

### Outcome A — strong methods-paper pair (most likely)
- R1 Nat Methods: indel prediction + complementary SAE signal + AlphaMissense
  diagnostic interpretation. Indel dataset released.
- R2 Nat Methods / Nat Mach Intel: CLT features as interpretable protein
  representation + universal circuit atlas.
- Optional R2 short safety paper on toxin/hallucination detection.

### Outcome B — clinical + methods package
- Same as A, plus P3-T3-A produces a retrospective Nat Med companion piece
  showing mechanism-driven therapeutic concordance.
- Conditional on rare-disease partnership.

### Outcome C — Nature-scope outcome
- One wet-lab validated discovery: either indel-MAVE pilot (P3-T3-B) or
  enzyme retargeting (P3-T3-D).
- This is the only path to a Nature/Science-tier paper from current state.
- Conditional on partnerships **and** a positive result.

If Tier 1 and Tier 2 deliver but no wet-lab is available, Outcome A is the
honest landing. If they don't deliver, the contributions narrow to a
"diagnostic methodology" methods paper for R1 plus a "negative
interpretation results" methods note for R2. Both are publishable, neither
is influential. The wet-lab path is the only door to influential outside the
methods community.

## 9. What NOT to Do

- Do not retrain CLTs at higher d_clt or longer schedule without first
  showing CLT features add value as a downstream representation (P3-T2-A).
  If they don't, no amount of retraining changes the story.
- Do not chase the channelopathy concordance number with more curation
  alone. The DN-on-KCNQ1 collapse is a real structural-mechanism limit,
  not a label-curation issue. P3-T1-E will tell us whether it is rescuable.
- Do not rebuild the SAE training. Layers 19/23/27/31/35 are sufficient.
  Adding layers does not change the gene-CV collapse.
- Do not write a "steering negative results" Nature submission. That is not
  a Nature paper.
- Do not promise wet-lab outcomes in any manuscript before a partner is
  confirmed (P3-T0-C).
- Do not add new external baselines now (PrimateAI-3D excluded; do not
  reopen). Three accessible scalar baselines + SAE+LLR is enough.

## 10. The Underlying Bet

We have a strong unique capability (indel mechanism prediction) and an
honest interpretability story (SAE features carry gene-level mechanism +
complementary pathogenicity signal). The previous pass exposed where we
overclaim — protein-CV mechanism collapse, ProteinGym negative, channel
DN→LOF, R2 steering null. The next pass should:

1. Capitalise on the unique capability (indels → dataset/leaderboard, scale-
   up, structural augmentation).
2. Frame the interpretability honestly (gene-level + residual, not variant-
   level mechanism).
3. Pivot R2 from steering to interpretable representation + safety.
4. Open the door to wet-lab partnership for the one path to a Nature-tier
   outcome.

If we do all four cleanly, R1 + R2 together is a strong Nat Methods package
with one Nat Mach Intel companion and a retained option on Nat Med or
Nature pending partnership. That is the most influential and beneficial
outcome achievable from current state.
